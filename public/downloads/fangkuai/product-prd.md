# 方块 · 项目知识助手｜产品需求说明

版本：作品集交付版 · 2026.10.09  
产品负责人：Wang Yuxiang  
阶段：本机工作台已实现；编辑式资料馆已部署独立交互演示；3位已确认的设计院同事参与试用，结构化测试记录待补充。

## 1. 产品定位

面向建筑设计与研究的资料助手，把历史项目、公开案例、规范与地区政策组织为可查找、可阅读、可核对、可再次使用的知识工作台。核心价值是缩短寻找依据的路径，并保留出处与适用边界。

**JTBD：** 当我开始一个设计任务、核对一个做法或比较多个项目时，我希望快速找到相关资料、确认原文并留下自己的判断，减少在文件夹、网页与笔记之间反复切换。

主要用户按任务区分：方案设计人员需要案例与设计思路；承担资料整理的设计人员需要原文定位与复用；项目负责人需要比较多个项目并核对依据。不同岗位的使用差异仍需后续访谈验证，不以虚构人物小传代替用户研究。

| 目标 | 已交付成果 | 产品边界 |

| 让知识有保存去处 | 独立演示打通浏览、阅读、收藏、摘录、研究夹回看 | 保存在当前浏览器；尚未接入私人库及跨设备同步 |

## 3. 核心体验与需求优先级

主路径：发现资料 → 打开原文与来源 → 摘录并写下判断 → 放入研究夹 → 回到来源复核。设计过程中出现局部问题时，再主动打开截图旁批。

| 优先级 | 需求 | 当前状态与下一步 |
|---|---|---|
| P0 | 可追溯问答 | 本机已实现检索、生成、引用与来源阅读；当前生成认证故障待恢复，不能承诺在线实时问答 |
| P0 | 真实资料与连续阅读 | 项目档案、文档目录、PDF分页及跨分卷阅读已实现；继续验证真实原文与返回位置 |
| P0 | 故障可解释、可恢复 | 取消、超时、重试、生成失败保留证据及项目卡片故障隔离已实现 |
| P0 | 新版接入与私有访问控制 | 编辑式界面尚需接真实接口；私库若上线，必须先完成登录与服务端资源授权 |
| P1 | 资料浏览与研究夹 | 新版演示已实现分类、搜索、主图、摘录及回看；下一步做账号内持久化 |
| P1 | 主动截图旁批 | 已完成交互方案；下一阶段接入上传、选区、真实分析和证据引用 |
| P2 | 导入与维护效率 | 继续优化可恢复任务、重复导入防护、规范版本更新及操作知识维护 |

桌面入口支持拖动、收起、置顶、托盘与按需启动本机工作台。重启电脑后需打开一次方块；本阶段没有设置系统登录自启动，也未形成脱离工程依赖的完整安装包。

## 4. 已有验收与尚待验证的结果

发布前生产构建与lint通过；请求恢复12/12、检索故障隔离7/7、桌面状态9/9、桌面启动12/12，合计40项回归通过。独立演示完成搜索、分类、来源详情、摘录刷新恢复及旁批回看检查；375像素视口无横向溢出，20/20张主图可解码。

这些是软件与交互验收。历史Phase 8的小样本检索结果为8道已知题Hit@1=7/8、Hit@3=8/8，原始16题包含1次生成失败；不能把它写成本轮扩库后的准确率。本轮公开案例、规范与政策各完成3项检索检查，共9项冒烟检查，未替代完整问答评测。

项目作者确认3位设计院试用参与者：徐工（高级设计师）、刘工（设计师助理）、缪工（总建筑设计师）。目前没有逐人原始访谈记录、效率对照或满意度数据，因此不发布量化用户成效。既有意见按作者汇总转述，不将某条意见绑定到个人，也不写成逐字引语。

## 5. 下一阶段：真实截图旁批

**目标场景：** 用户在CAD或建模过程中，对局部入口、流线、空间关系或软件操作有疑问，希望获得一次简短的辅助判断，然后继续设计。

输入由用户主动提供：上传或粘贴截图、框选区域、补充问题；软件操作题同时提供软件名称、版本与系统。发送前展示实际选区，支持遮挡敏感内容。没有比例、单位或条件时，先询问，不从图片猜测精确尺寸。

输出分为观察、待确认信息、建议与依据。软件问题优先给命令名和菜单路径，快捷键注明适用版本及可能的自定义差异。每条旁批可保存、追问、返回选区或关闭；默认不展开，不持续捕获屏幕，不自动修改模型。

**拟定验收门槛，尚未执行：**

- 上传、选区、预览、提问、取消、失败重试和保存回看形成完整路径；取消后不继续更新界面。
- 输入不充分时明确询问；测试集中不得把无尺度截图转换成确定的尺寸或法规结论。
- 引用可打开对应来源；区分来自截图的观察、资料证据和模型建议。
- 软件命令在目标版本验证；未知或不确定的快捷键不能补写成确定答案。
- 保存后重新进入可恢复原图与选区；收起旁批后不占据主要绘图区域。
- 先开展小范围真实任务测试，保留失败与误判，再决定是否增加插件级操作能力。

## 6. 指标定义与测量计划

| 指标 | 定义 | 现状 |
|---|---|---|
| 找到依据的耗时 | 从接收任务到打开经审核的正确原文，用配对任务比较手动查找与助手路径 | 待测，不写节省百分比 |
| 任务成功率 | 无主持人补救且找到足够依据的任务数／全部尝试任务数 | 待测；按角色与任务类型记录 |
| 证据支持率 | 有对应原文支持的关键断言数／抽查关键断言总数 | 历史小样本已有审核；扩库后需重新评估 |
| 未知问题拒答率 | 应拒答题中正确说明缺证据的题数／全部应拒答题数 | 保留历史结果，新增独立测试集 |
| 旁批有用性 | 用户确认帮助推进当前问题的旁批数／实际阅读的旁批数，同时记录误导与打断 | 待真实视觉版本实现后测量 |
| 运行可靠性 | 请求成功、取消、超时、生成失败与恢复分别计数，记录总耗时和调用数 | 已有故障验收；需补持续运行数据 |
