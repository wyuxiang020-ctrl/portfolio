## 网页实现

- 沿用既有项目的英文短标题、中文副标题、中文正文与图注。
- 用真实项目素材替换旧页的 4 张 Unsplash 占位照片，更新封面、合作署名与项目简介。
- 删除旧页中资料不能支持的笼统文化断言，按本项目的观察、设计意图和图纸组织叙述。
- 以设计方案、效果图和实体模型表述成果，不声称已建成、完成工程验证或进行了入住后评估。
- 效果图提取 PDF 内嵌主图，去掉页标题与侧边说明，保留原比例，不人工放大像素。
- 分析/图纸按长边 3200 像素渲染；最终 PDF 的部分标题与比例尺靠近纸边，因此完整保留其画布，避免统一裁边截断标注。
- 复用 OptimizedImage 的 WebP 多尺寸输出、图片宽高、懒加载和 PhotoSwipe 大图。清晰度仍受用户提供的压缩 PDF 限制。
- 新增通用章节导航/补充内容样式，沿用原 ITB 样式；项目二级标题增加顶部避让，章节跳转后不被固定导航遮住。
- 未修改 ITB 3D 查看器，未给本项目新增无来源的 3D 模型。
