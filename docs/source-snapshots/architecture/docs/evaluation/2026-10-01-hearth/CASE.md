# 可同步作品集的准确表述

针对建筑空间展示网站中“祖母的火塘”完整模型在公网下载超时的问题，我先核对既有模型优化与托管方式。确认模型已采用实例化、Meshopt 和 WebP，服务器已有 Brotli 后，没有继续删减建筑细节，而是将火塘的单请求传输调整为有上限的分段并发，并补充版本、范围、GLB 文件头和整份 SHA256 校验，保留取消、重试与完整请求回退。

原文件内容保持不变。前轮真实公开资源测试在 300 秒时仍未完整下载；本轮一次公开软件测试用时 172.561 秒取回全部 23,820,388 字节，46 个请求，校验值与原文件一致并通过解码。另通过 22 项分段下载回归和 9 项既有控制器测试。前后测试并非受控用户实验，不能外推普遍提速比例、访客成功率或满意度提升。

我的产品工作包括问题收敛、技术方案与保真取舍、失败恢复要求、证据分类和发布验收。AI 工具辅助代码实现与检查；网站没有面向访客的 LLM 推理功能。本轮结果属于真实文件的软件传输验证，作者自测、浏览器可见首帧、真实手机与真人理解测试仍未完成。模型原建筑成果保留 Yuxiang Wang · Han Liu 联合署名，网站产品工作与建筑个人设计贡献分开表述。
