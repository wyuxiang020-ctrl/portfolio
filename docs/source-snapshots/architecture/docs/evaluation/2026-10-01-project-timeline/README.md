# 中文身份、首页策展与全部项目时间线

本轮版本标识：`portfolio-timeline-2026-10-01`。正式入口：https://yuxiangworks.com/ 。发布状态与最终提交见本目录 `release.json`（发布验收后生成）。

## 目标与范围

用户反馈：中文网站缺少醒目的中文姓名；首页只显示三张精选卡片，访客容易误以为仅有三个项目；希望每个项目有简要介绍并按时间排列；火塘应进入精选；ITB 与火塘应明确刘涵的合作署名。

本轮保留现有首屏背景与首页总体视觉，不更换成建筑代表作；集中调整身份、项目目录和署名。3D 模型、加载逻辑、材质与控制没有修改。

## 验证与证据边界

- 本地生产构建通过，共 11 个静态页面；保留既有 3D 脚本大于 500 kB 的构建提示。
- 静态验收见 `static-checks.json`；浏览器操作记录见 `browser-checks.json`。
- 本地 Codex 浏览器核对桌面与窄屏；窄屏请求 375 × 812，实际 DOM 可用宽度为 360 px（滚动条占用），属于软件模拟，不是真实手机。
- 已实际点击：首页全部项目入口 → 时间线 → 火塘详情 → 全部项目。核对双方署名和 7 项目录。
- 截图来自本地生产构建，正式部署另以匿名公开请求核对版本；不可把本地截图称为正式站真实设备验收。
- 自动化软件检查与代理浏览器操作不等于作者本人自测、真人读者测试。没有访客 AI 模型调用、固定响应回放或准确率评测。
- 当前网络是否使用 VPN/代理未确认；历史曾开启 VPN，不将本轮公共 HTTP 检查表述为国内无 VPN 直连。

- 代码复核发现全部作品页复用组件造成 h1 后直接 h3；为组件加入标题级别参数，首页保留 h3，全部作品页使用 h2，重新构建通过。
- 首屏立即截图时文字尚处于原有淡入动画；后续截图姓名正常显示，没有把过早截图认定为页面缺字。
- 页面切换瞬间一次窄屏测量出现 scrollWidth 375 / clientWidth 360；切换结束后为 360 / 360，未发现稳定横向溢出。保留瞬态观察，不编造修复或性能提升。
