## 目标与取舍

用户授权减少材质，目标是降低传输、贴图解码与上传开销，同时保留院落与建筑空间。完成标准：文件显著缩小、独立几何检查通过、浏览器正常显示、视角/图层/恢复/关闭重开和错误重试通过，公开文件与本地版本一致。

## 已执行验证

- `model.json`：可复现转换记录、材质映射、前后体积和图层。
- `validation.json`：独立 glTF 检查、位置/绕序、实例世界变换与镂空纹理对照。法线重复编码存在最大约 0.54° 差异，不宣称所有二进制完全相同。
- 四份压缩/解码检查均 0 错误、0 警告、未截断。信息项仍有未由通用验证器覆盖的扩展、非二次幂贴图；轻量版解码有 16 条退化三角形信息（涉及 2,484 面），来自去 UV 后焊接重合顶点。三角形位置和绕序仍逐一匹配，未为消除信息项额外改几何。
- `before-browser.json`、`after-browser.json`：Windows 本机 Codex 内置浏览器，由代理操作实际 Three.js/WebGL 页面，localhost，无网络限速。原版一次点击到首次提交绘制 1,707ms，轻量版一次 495ms；轻量版关闭重开一次 253ms。它们是渲染提交时间，非显示器实际出帧测量；缓存未严格控制，不能外推用户体验。
- 本地真实 UI：俯视、侧面、场地图层隐藏、恢复、键盘缩放、关闭后 canvas 数量为 0、重新打开均通过；截图见 `before.png`、`after-overview.png`、`after-layer.png`。
- `recovery-browser.json`：本地注入首次 HTTP 503，78ms 报错，显示继续阅读和重新加载提示；随后重试真实轻量模型，269ms 到首次绘制提交。故障是确定性 HTTP 夹具，不是 AI 回答回放，也不是公网故障成功率。

## 首次失败与修正

1. 转换脚本首次调用 ColorUtils 缺少输出参数，停止于生成文件之前；补充目标数组。
2. Sharp 的缩放颜色转换在本机失败，改用直接统计原贴图通道均值；不安装额外工具。最终转换约 5 秒。
3. 独立检查最初直接比较实例四元数，误将 q 与 -q 的等价旋转判为变化；改为比较实际世界矩阵。保留 `validation-first.json` 与运行历史，不删除失败记录。
4. 验证器因大量 UNUSED_OBJECT 信息截断，改为仅忽略该信息并要求错误检查未截断。详见运行历史。
5. 浏览器环境只读接口不提供 navigator，环境采集尝试报错；没有影响页面或模型，记录为工具限制。
