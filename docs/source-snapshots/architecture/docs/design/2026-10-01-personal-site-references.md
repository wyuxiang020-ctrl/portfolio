# 个人作品网站参考与改进建议

2026 年 10 月 1 日核对。当前优先方向是个人识别、代表作选择、项目阅读层级和可信度。本轮是研究与提案，没有修改或发布网站产品代码。

## 五个参考网站

| 网站 | 官网可核实的特点 | 对你网站的启发 |
| --- | --- | --- |
| [Alex Hogrefe](https://visualizingarchitecture.com/) | 建筑项目、图像和制作教程相互连接；[MIT 分析页](https://visualizingarchitecture.com/mit-site-plans-and-diagrams/)展示底图、改造前后和图形迭代 | 挑一处关键设计，配“原问题—选择—空间变化”与同视角图纸。先解释每张图承担的论证，再选择表现效果 |
| [Brittany Chiang](https://brittanychiang.com/) | 明确的职业定位、经历、项目、简历与写作入口 | About 开头先交代专业与关注方向，再用具体项目和确认过的职责提供证据；个人故事放在其后 |
| [Pablo Stanley](https://www.pablostanley.com/) | 项目名称、简短介绍、链接与时间组成作品索引，同时提供[探索版本](https://world.pablostanley.com/) | 图片文字形成完整阅读路径，3D 作为进一步理解的可选入口；精选项目分别体现不同能力 |
| [Rauno Freiberg](https://rauno.me/) | [Craft](https://rauno.me/craft)连接交互实验、原型与正式作品；[交互文章](https://rauno.me/craft/interaction-design)讨论可中断操作、空间一致性和阅读位置 | 在已有功能基础上完善当前章节、手机点击提示和键盘焦点；每轮解决一个具体操作问题 |
| [Bruno Simon](https://bruno-simon.com/) | 驾驶探索式 3D 作品集，提供画质、重置、脱困和多种输入说明 | 学习清楚的操作与恢复机制。你已有视角、恢复和关闭，不重复开发；全站 3D 化会带来新的性能与操作成本 |

上表优势及适用性是本轮分析判断，不是转化率、满意度或性能测量结果。推荐按表格顺序学习。读案例时，每次记录一个内容问题、一项界面选择和一种能映射到自己项目的做法。

## 当前网站对照

本轮匿名读取正式首页、联系页及火塘页均为 HTTP 200，火塘页仍为 `spatial-ux-2026-10-01-parallel-load`。这是 HTML 检查，不代表完整加载或真机体验。浏览器自动打开参考站超时；案例分析依据官网可读取内容，不冒称已操作所有交互，也不提供截图或速度排名。

| 优先级 | 已确认的现状 | 建议 |
| --- | --- | --- |
| 高 | 首页整屏首图仍来自外部 Unsplash，项目在介绍文字之后 | 用自己的代表作做响应式首图，并提供明确的作品入口 |
| 高 | 首页按标记与顺序选前三个项目，火塘尚未入选 | 重新策展三件作品，各自代表建筑改造、文化与社区、数字方法等不同能力；最终取舍依求职方向确认 |
| 高 | Instagram、Behance 仍指向 `#` | 有真实地址则填入，否则移除占位项；现有邮箱、电话、小红书继续使用 |
| 中 | ITB／火塘已有目录，其余项目没有统一目录；现有目录会随页面滚走 | 先在一个长项目试验可展开目录和当前位置，避免遮挡手机图纸 |
| 中 | 已有联合署名，个人负责内容尚不统一 | 根据确认过的事实补充职责；区分原建筑设计、网站产品工作与 AI 协作 |
| 中 | 正文默认约 13.6 px，部分提示依赖悬停，中文主体页面语言固定为 en | 比较更易读的正文样式，完善触屏与键盘入口，修正语言标记；实际可用性需验证 |
| 中 | 全站字体依赖 Google Fonts，首图依赖 Unsplash | 评估自有首图、所需字体自托管与回退；是否改善国内访问须实测 |

来源为 `Hero.astro`、首页及项目内容、`Footer.astro`、`contact.astro`、`BaseLayout.astro` 与 `global.css`。

已完成并应保留：响应式图片、宽高、懒加载、图片灯箱及键盘入口、关闭后位置恢复、减少动效、阅读进度、回到顶部、ITB／火塘章节导航、前后项目切换和手机单列布局。不把它们再写成新的开发成果。

## 建议下一轮范围

主题：让访客在首页看到真实作品与明确的专业方向。

范围：更换一张自有作品首图、提炼一句定位、提供清楚的作品入口、重新选择三件精选作品；清理空社媒链接。保留建筑网站的名称与视觉基调。

建议顺序：姓名与专业 → 一句关注方向 → 查看代表作 → 三个精选项目 → 简短介绍 → 联系方式。

可讨论的定位句：“关注既有建筑更新、文化叙事与数字化空间表达。”这是文案提案，不是新增资历。AI 产品能力通过对应案例中的真实迭代与测试证据体现。

完成标准：首屏作品可识别、入口可键盘访问、手机无横向溢出与文字遮挡、精选及联系方式链接有效，并记录同条件下的首图加载数据。没有真人测试，就不声称用户理解、效率或满意度已经提升。
