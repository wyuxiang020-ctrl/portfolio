## 建议处理顺序

1. **先导出忠实的工作副本**：按当前可见模型空间范围读取缓存网格，排除布局视口、辅助曲线和填充；保留建筑相关图层、实例变换、基本材质及源对象标识。导出后与 Rhino 原始视图对照，确认没有构件丢失、镜像反转、单位或坐标错误。若缓存导出无法保真，再用 Rhino 原生导出重建网格。工作副本只用于本地核验，不是直接发布的最终文件。
2. **处理重点图层**：辨认屋顶花园和 Layer0 中高面数重复对象；优先复用实例几何，再对非关键细节尝试减面。主体墙、楼板、梁柱、入口和主要交通空间优先保持。拱形屋顶减少网格细分时需检查轮廓，不能只追求面数。
3. **整理材质和贴图**：比较真实材质参数和纹理后合并重复项；不要跨越需要独立切换的构件分组强行合并。验证 Enscape／Rhino 材质映射，必要时制作忠实的网页 PBR 材质。纹理按显示用途调整分辨率。
4. **形成网页候选版本**：建议先尝试 30万—60万三角面、GLB 10—20 MiB 以内，均为待实测目标而非承诺。如果视觉损失明显，保留较高细节版本，改用分层按需加载。使用几何压缩前确认查看器支持对应解码器。
5. **接入查看器再验证**：旋转、缩放、平移、重置、3—4 个有效预设视角。加载前显示静态图，用户点击后才请求 GLB；记录实际加载耗时、手机内存与旋转流畅度，再决定是否需要轻量版。

- 7 个命名视图都未使用空间名称，应在视觉核对后由作者确认入口、关键空间等名称。
