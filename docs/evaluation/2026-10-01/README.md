# 2026-10-01：持续下载被总超时中断的修复

## 本轮目标、范围与完成标准

核对最新代码、运行环境与公开版本；修复已有 3D 加载路径中的一个阻断问题：网络持续返回数据却在 90 秒被强制中止。最多一项相关体验完善：失败提示说明原因和恢复方式。保留按需加载、视角、图层、恢复、关闭/重开及上轮取消功能，不重复开发；不增加聊天、AI 控制、轻量模型等产品模块。

工程完成标准：在同一真实 GLB 的受控慢速连接上保留旧版首次失败，新版完整传输且 hash 一致；覆盖停滞、最长等待、截断、503、取消与重试；构建成功，记录发布版本。浏览器端可见模型、操作连续性与真实设备是独立验收项；连接工具不可用时明确未验证，不把工程测试代替它们。真人招募不再是工程迭代的前置条件，旧 TASKS.md 与 readers.csv 保持未测。

## 基线与修改

读取 9 月 30 日最新交付报告及 release.json，核对 Git/线上均为 `b494d9d5a87e1aa39f5852da6033e04261aa503e`。本地 Node 24.16.0、npm 11.13.0，Windows；系统代理开关为 0，但 VPN/隧道未知。匿名公开 HTML 保存为 public-before.html，原版本标识仍在。未改动用户的 .claude 设置及历史未提交资料。

| 项目 | 修改前 | 修改后 |
|---|---|---|
| 持续下载 | 90 秒总计时直接 abort | 连续有数据可继续，45 秒无数据中止，下载最长 5 分钟 |
| 失败说明 | 统一“暂时无法打开” | 区分停滞、最长等待、数据不完整，均有重试/继续读图路径 |
| 数据完整性 | 下载结束即进入解析 | 对照构建时真实文件字节数，缺失/超出时进入恢复提示 |
| 取消、视角、图层、恢复、关闭 | 已存在 | 保留，不作为本轮新增成果 |

下载计时不包含动态脚本导入及几何解析；本轮不宣称能中断主线程解析。较慢但持续的网络仍可能超过 5 分钟，届时仍需换网络/重试；未引入自动重复下载或续传。图层语义与相机未调整。两份 GLB 的 hash 与上一轮一致，未删减建筑设计细节。

## 验证分层与结果

1. **真实大模型调用：无。** 本网站不调用面向访客的 LLM；没有模型准确率、token 延迟或 AI 推理成本可评。
2. **固定 AI 响应回放：无。** 测试中的固定 HTTP 503、停滞与截断属于故障注入，不是 AI 回答回放。
3. **自动化软件测试：** 使用真实 ITB GLB 字节经本地 HTTP 每秒发送一块，100 块。旧生产代码提取原读取循环，90.005 秒 AbortError；新下载器 101.048 秒完整收到 6,539,052 字节，SHA256 一致。每版 n=1，环境受控；这是失败转完成，不是下载提速/真实公网用户成功率。transfer-before.json 与 transfer-after.json 保留原值。首次测试脚本曾因 TypeScript 非空断言转译遗漏而启动失败，单列 harness-first-failure.txt，不计为产品失败。
4. **自动化软件测试：** download-tests.json 的 9 项通过，包括两个真实文件本地传输 hash、503、停滞、持续流量达到最大上限、截断、两种取消及失败后重试。故障测试计时缩短至 200/500ms，仅测试分支，不等同于生产 45 秒/5 分钟测量。lifecycle-tests.json 的 9 项控制器测试通过，加载器为 mock；其中 3 项验证具体失败提示和可重试，其余复用上轮取消/换页/重复初始化回归。
5. **真实公开资源：** public-models.json 使用当前下载器匿名获取线上原 GLB、hash 核对、NodeIO/Meshopt 解码，n=1/模型。成功/失败及耗时按该文件原始记录；它验证的是传输/数据可解码，不是 Three.js 可见首帧或 GPU 交互。当前路线是否 VPN 未确认，不算大陆直连。
6. **浏览器软件验收：** 本轮页面创建/导航请求超时 20 秒；按恢复指导连接已有页读取 DOM 再超时 15 秒。没有取得可见首帧、滚轮缩放、隐藏恢复、返回位置或重开实测结果，不沿用旧历史数值冒充本轮。手机真机、作者亲自自测、外部真人参与者均为未测（n=0）。工具操作不标为作者自测。

可得成本：测试没有付费 LLM API，推理调用数 0；真实 GLB 本地字节分别 6,539,052 / 23,820,388，公开测试实际收到字节记入 JSON。没有取得 Vercel 带宽/构建账单，不能声称所有运行成本为零；开发订阅、人工时间和访问网络费用未核算。现有依赖，无新增付费服务。

## 正常和失败恢复演示

正常：[ITB](https://yuxiangworks.com/work/iterative-learning/?modelTest=1#interactive-model) / [火塘](https://yuxiangworks.com/work/grandmothers-hearth/?modelTest=1#interactive-model)。打开 → 选择视角 → 取消图层勾选 → 恢复全部 → 关闭 → 重开。测试模式离页前下载记录；界面截图与作者结果尚待实测，不作为本报告已通过步骤。

失败：加载中可取消再打开；停滞/总等待/数据不完整显示原因，点击“重新加载模型”重新请求，可继续读已有图纸。为可重复演示 HTTP 失败后恢复，保留本地故障代理：先运行预览 4322，再运行 `node scripts/serve-model-test.mjs --recover`，打开 `http://127.0.0.1:4324/work/iterative-learning/?modelTest=1#interactive-model`。每个模型第一次返回固定 503，下一次请求转发真实 GLB；重启代理重置此状态。这是本地故障夹具，不是线上自然故障，不上传到产品页面。原不带参数的 503 模式仍保留。核心自动化重试路径另有 test-model-download.mjs 验证。

## 停止条件与剩余限制

本轮不再扩展新功能。工程修复与测试达到上述标准后停止；浏览器端完整验收仍受工具连接阻塞，不把它改写为已完成。真实设备与用户理解继续“未测”，但不阻止后续有独立证据的工程维护。公网带宽、外部图片/字体、触屏滚动、图层可理解性、火塘无法单独隐藏屋顶等旧限制未由本轮解决。

最终发布状态、Git、部署 ID 与线上核验见 release.json；没有成功记录时不视为已发布。作品集准确表述见 CASE.md。
