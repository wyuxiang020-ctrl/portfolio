# 圆形建筑入口 · 第一版

日期：2026-10-07。路由 `/studio/`，本地成品预览 `http://127.0.0.1:4321/studio/`。

本轮实现以连续曲面墙从波浪形态围合成圆馆为主线；AI 实验馆、建筑展馆、个人工作室分别带有不同陈设。支持围合滑杆、重播、三维物体拾取、镜头靠近、屋顶抬升、拖动旋转和昼夜灯光。项目入口连接现有案例页面。

## 验证

- `npm run build`：26 个静态页面成功构建。
- `npm run check:links`：1,622 个本地引用，0 个失败。
- 正式静态预览中验证自动入场、选中 AI 馆、重播中退出选馆、全部屋顶打开、昼夜切换。
- 点击三维场景中个人馆的桌面可选中对应空间；拖动建筑场景只旋转，不会误选。
- 验证建筑馆与个人馆详情、返回总览、焦点转移；AI 作品链接可到达知识助手案例，浏览器返回后场景正常初始化。
- 检查桌面、390 × 844、320 × 740 视口。两种手机宽度均无文档横向溢出。手机选馆后详情滚入视口。
- 成品预览检查时控制台无 error / warn。
- 修正了旋转期间重复安排动画帧、隐藏家具被拾取、围合滑杆值被插值覆盖、夜景背景接缝、手机标题换行与窄屏场景裁切。
- reduced-motion 静态呈现与 WebGL 失败后的原生链接入口已在代码中实现；本轮没有模拟系统减弱动态效果或强制 WebGL 上下文失败。
